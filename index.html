FAQ

Common questions

What Python versions does VulnScope support?
VulnScope supports Python 3.9 and above. The scanner itself requires Python 3.9+; the dashboard runs on Node.js 18 LTS or later. Both are available on Windows, macOS, and Linux.
Does VulnScope scan JavaScript or TypeScript projects?
Currently VulnScope is optimized for Python projects (CVE detection via pip packages, SAST rules for Python). JavaScript/TypeScript scanning is on the roadmap. The web header scanner works for any domain regardless of stack.
What happens to my code during a scan?
Your code never leaves your machine. VulnScope runs entirely locally. The only outbound request during a scan is to OSV.dev to fetch CVE metadata for your package names and versions — your actual source code is never transmitted anywhere.
What happens after 12 months?
The license is lifetime — VulnScope continues to work indefinitely. The 12-month update period means you receive new features and scanner rule updates for one year. After that, your existing version keeps working; you just won't get new feature releases automatically.
Can I use it for client projects or bug bounties?
Yes — the license permits use on projects you own or are authorized to test, including client work (with engagement authorization) and bug bounty targets listed in a program's scope. It is not permitted to scan systems you do not have authorization for.
What do I get in the download?
A ZIP archive containing: the VulnScope Dashboard (Next.js standalone build), the VulnScope CLI Python scanner, setup scripts for Windows (PowerShell), macOS/Linux (bash), and Docker, plus INSTALL.md with step-by-step instructions. No internet required after initial setup.
